# modmyclaude brand

## The mark

**Bolt**, a 16 x 14 pixel agent buddy with a signal light on its antenna. Always drawn on the pixel grid with crisp
edges (`shape-rendering="crispEdges"`, `image-rendering: pixelated`). Never smoothed, rotated, outlined or recoloured
outside the palette below.

| File | Use |
| --- | --- |
| `mascot.svg` | The buddy alone, transparent |
| `icon.svg`, `png/icon-*.png` | App icon and favicons (buddy on an ink tile) |
| `logo-on-dark.svg`, `logo-on-light.svg` | Horizontal lockup (buddy + wordmark) |
| `wordmark-on-dark.svg`, `wordmark-on-light.svg` | Wordmark alone, outlined (no font needed) |
| `png/social-preview-1280x640.png` | GitHub social preview and Open Graph image |

## Wordmark

`modmyclaude`, lowercase, one word, Space Grotesk Bold, tracking -2%. "mod" takes the accent: lime on dark,
deep lime `#4F7A00` on light. Never split into "Mod My Claude" in the logo, never title case.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Ink | `#101114` | Dark background, text on light |
| Paper | `#F5F6F1` | Light background, text on dark |
| Lime | `#C8F53C` | The one accent: fills, the "mod" in the wordmark |
| Lime shade | `#9BC21A` | Mascot shading only |
| Deep lime | `#4F7A00` | Lime-family text on light backgrounds (AA contrast) |
| Signal pink | `#FF5C8A` | The antenna light only. Never a UI colour |
| Blush | `#FF8FB1` | Mascot cheeks only |

One accent per surface: lime. Pink lives on the mascot and nowhere else.

## Type

- Display and wordmark: Space Grotesk (OFL)
- Body: Geist
- Code and install lines: Geist Mono

## Never

- Anthropic's marks, colours (terracotta) or mascot, and any wording that implies we are official
- Sparkle icons, emoji in product copy, em dashes anywhere
- Gradients or glows on the mark
