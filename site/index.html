Install your first mod

> /plugin install last-look --marketplace modmyclaude/claude-code-mods
  • Needs Claude Code 2.1.287 or newer. Run claude update if you are behind.
  • Type the line in Claude Code running in a terminal, then answer y to add the marketplace.
  • Mods installed at user scope also load in the desktop app.
  • The VS Code extension draws mods from extension 2.1.299 (2.1.304 when the session does not fetch feature flags). Every mod here is tested on the terminal and the desktop app, so check its README before relying on it in VS Code.

      03 Safety

      What a mod can do

      1. Mods run with your permissions

        They are not sandboxed. A mod can see your prompts and tool calls, so only install mods you trust.

      2. The badges are not our claims

        "Can reach" comes from Claude Code's own validator, run every time the catalogue is built. A mod that reads files, runs commands, calls a model or uses the network says so.

      3. Every mod is reviewed and tested

        A second maintainer reviews each mod against its prompt. Strict validation and the mod's own tests run on every commit.

      4. "Unverified" means look first

        The validator could not report on that mod when the catalogue was built. Read its code before you install it.
