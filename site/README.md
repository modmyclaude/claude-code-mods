# site/

The gallery at https://modmyclaude.github.io/claude-code-mods/, served by GitHub Pages from this folder.
Static files, no build step, no dependencies.

| File | What it is |
|---|---|
| `index.html` | The page skeleton: hero, catalogue, build your own, safety, footer, detail dialog. |
| `style.css` | All styles. Colour tokens live on `:root`; dark mode swaps them under `prefers-color-scheme`. |
| `app.js` | Fetches `mods.json` and renders cards, filters, the detail dialog and starters with plain DOM APIs. |
| `mods.json` | Generated by `scripts/build-catalog.mjs`. Do not edit by hand. |
| `favicon.svg` | The tab icon. |
| `media/` | Optional previews for each mod (see below). |

## Media files

Each mod card has a media slot. Drop a file into `media/` named after the mod's `name` in `mods.json` (the folder name under `mods/`):

```
media/<name>.gif    looked for first (an animated clip of the mod working)
media/<name>.png    looked for next (a still)
media/<name>.webp   looked for last
```

For example `media/redline.gif`, `media/redline.png`. Lowercase, exactly the mod name, no other suffixes.

- If none of the three exist, the card shows a generated placeholder built from the mod name. There is never a broken image.
- Visitors who ask their system for reduced motion get the still first (`.png`, then `.webp`, then `.gif`), so ship a `.png` alongside any `.gif` when you can.
- The slot is 16:10 and crops from the top left. Record at 1280 x 800 (or 640 x 400) so nothing important is cut off.
- Keep clips short (6 to 10 seconds) and under about 2 MB. Media loads lazily as cards scroll into view.

### Skipping the lookup

While a mod has no media, the browser asks for all three filenames and gets 404s, which show up in the console. If `mods.json` ever carries a `media` field per mod, the page uses it instead of guessing:

- `"media": "redline.gif"` loads exactly that file from `media/`.
- `"media": null` means no media: the placeholder shows and nothing is requested.
- No `media` field: the page looks for `.gif`, `.png`, `.webp` as above.

## Preview locally

```
cd site
python3 -m http.server 8080
```

Then open http://localhost:8080/. Opening `index.html` straight from disk will not load `mods.json`.
